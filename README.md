# Paradise Nursery

Paradise Nursery is a shopping cart web application for an online houseplant shop, built with React and Redux Toolkit.

## Features
- Landing page with company name, background image, About Us section and a **Get Started** button
- Product listing with 18 houseplants in 3 categories (Air Purifying, Aromatic Fragrant, Succulents and Cacti), each with thumbnail, name and price
- **Add to Cart** button that adds the plant, disables itself, and updates the cart icon count
- Navbar with Home, Plants and Cart links on the product and cart pages
- Cart page showing thumbnail, name, unit price, per-item total and overall total
- Increase / decrease quantity buttons and a Delete button for each item
- **Checkout** button (shows "Coming Soon") and **Continue Shopping** button

## Tech Stack
React (Vite), Redux Toolkit, React-Redux, CSS

## Run Locally
```bash
npm install
npm run dev
```
